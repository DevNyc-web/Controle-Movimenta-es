# Instalar o sistema na tela inicial do celular

O sistema é um web app instalável (PWA). Continua sendo o site: não há app nativo, nem cache offline (dados sempre vêm do servidor).

## Android (Chrome)
1. Abra o endereço do sistema no Chrome e faça login.
2. Menu ⋮ → **Instalar app** (ou **Adicionar à tela inicial**).
3. Confirme. O ícone do Grupo MC aparece na tela inicial e abre em tela cheia.

## iPhone / iPad (Safari)
1. Abra o endereço no **Safari** (outros navegadores no iOS podem não oferecer a opção).
2. Toque em **Compartilhar** → **Adicionar à Tela de Início** → **Adicionar**.

## Limitações
- Sem modo offline: sem internet o sistema não abre (intencional, dados corporativos).
- iOS: só o Safari instala com ícone próprio; não há botão "Instalar" automático.
- Firefox Android: permite atalho, mas pode abrir em aba comum do navegador.
- Se o logo for trocado, é preciso remover e adicionar o atalho de novo para atualizar o ícone.
